# Hướng dẫn sử dụng cho Nhân viên

1. **Quản lý tài khoản**: Thêm tài khoản Facebook / LinkedIn kèm proxy.
2. **Cài đặt chiến dịch**:
   - Chọn nền tảng (Facebook / LinkedIn).
   - Thiết lập từ khóa quét.
   - Nhập nội dung mẫu và bật AI sinh biến thể (Entity Lock sẽ khóa SĐT, giá, link).
3. **Thực thi**: Bấm Bắt đầu. Bộ Scheduler và Guards sẽ tự động kiểm soát giãn cách và dừng khi có checkpoint.
4. **Báo cáo**: Lọc và xuất file Excel kết quả.
